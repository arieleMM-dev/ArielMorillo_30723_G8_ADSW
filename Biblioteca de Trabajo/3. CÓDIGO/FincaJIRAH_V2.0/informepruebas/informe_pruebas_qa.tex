\begin{alertinfo}
\textbf{\faInfoCircle\ Nota metodológica:} Cada Caso de Uso (CU) se descompone en Casos de Prueba atómicos (TC) que verifican un único escenario con mocks de dependencias. La organización CU $\to$ TC constituye la Matriz de Trazabilidad requerida por el Plan QA, combinando \textit{pruebas unitarias puras} (funciones de dominio) con \textit{pruebas unitarias de servicio} (lógica de negocio con repositorios mockeados).
\end{alertinfo}
